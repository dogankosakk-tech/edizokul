Ediz Okul

Ailece okul parasını takip et. USD ödemeler seçtiğin tarih/saatteki TCMB döviz alış kuruyla TL’ye çevrilir.

Paylaşımı aç (tek sefer)

Sunucu çalıştırmana gerek yok. Ücretsiz Firebase ile aile aynı linkten canlı görür. Bilgileri buraya yapıştırman yeterli — dosya düzenlemen gerekmez.

  1. Firebase Console → Add project → isim: edizokul
  2. Build → Realtime Database → Create → europe-west1 → test mode ile başla
  3. Project settings → Your apps → Web → firebaseConfig kopyala
  4. Rules (aile içi link; yalnızca güvendiklerinle paylaş): 
    {
  "rules": {
    "rooms": {
      "$roomId": {
        ".read": true,
        ".write": true
      }
    }
  }
}

Kayıttan sonra rozet Canlı paylaşım açık olur. Aile linki bu ayarı da taşır; diğer üyelerin ekstra kurulum yapması gerekmez.
